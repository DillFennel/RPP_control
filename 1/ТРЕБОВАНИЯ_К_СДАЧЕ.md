# Порядок сдачи

Учебный счётчик — заготовка. Сдаваемая программа должна решать индивидуальный вариант преподавателя.

## Перед реализацией

Отправить преподавателю протокол: список команд и аргументов, форматы успешных ответов и ошибок, framing, ограничения и 2–3 примера сессий, включая ошибку. По документу должно быть возможно написать клиент без просмотра сервера.

Язык — C++, транспорт — TCP, клиент — консольный. Состояние хранится в памяти и принадлежит сессии. Сервер не должен падать на неверной команде, клиент должен разбирать ответы и ошибки. Использовать ИИ разрешается, но нужно понимать весь код.

## Архив

Выбрать Windows или macOS и упаковать содержимое соответствующей папки:

```text
протокол.md
README.md
CMakeLists.txt
server/
    server.cpp
client/
    client.cpp
```

Протокол лежит строго в корне архива. Общих заголовков или папки common в упрощённой версии нет. В README приведены команды сборки и запуска.

Отправить один архив до конца пары. Для протокола и итогового архива использовать тему письма:

```text
Фамилия Имя, группа, вариант N
```

Если менялись команды или ответы, обновить итоговый протокол. На защите вопросы будут именно по этой версии.

## Защита

Показать запуск, команды и обработку ошибок; быть готовым объяснить сокеты, framing, парсинг и состояние, а также изменить код на месте.

По требованиям: протокол — 4 балла, сервер — 10, клиент — 6; коэффициент понимания k равен доле правильных ответов, итог указан как 20 × k. При отсутствии понимания кода k = 0.

Проверить перед отправкой:

- протокол отправлен заранее и есть в корне итогового архива;
- папки server и client содержат исходники;
- сборка выполняется по README;
- некорректная команда возвращает ERR и не меняет состояние;
- новое соединение начинает с начального состояния;
- программа соответствует варианту и итоговому протоколу;
- тема письма содержит фамилию, имя, группу и вариант.
