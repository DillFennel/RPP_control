# Самостоятельная работа №1 — вариант 5

TCP-сервис генерации случайных последовательностей на C++17. Сетевые вызовы идут в порядке из презентаций: `socket → bind → listen → accept` у сервера, `socket → connect` у клиента. Для сети используются системные сокеты: Winsock в Windows и POSIX в macOS; строки, потоки, контейнеры и генератор — стандартная библиотека C++.

## Возможности

| Команда | Пример | Назначение |
| --- | --- | --- |
| /generate | /generate DIGITS 10 | Сгенерировать строку длиной 1–128 |
| /seed | /seed 42 | Установить seed от 0 до 4294967295 |
| /check | /check LETTERS AbCd | Проверить соответствие символов типу |
| /history | /history | Показать до пяти последних результатов |
| /quit | /quit | Завершить сессию |

Типы: DIGITS, LETTERS, ALNUM, PUNCT. Буквы — латинские, обоих регистров. /check проверяет алфавит, не происхождение строки. Числовые аргументы — десятичные цифры без знака.

В каждой сессии свой генератор `std::mt19937` с начальным seed 5489 и своя история. Повторный /seed воспроизводит последовательность при одинаковых запросах в той же реализации программы; история сохраняется. После отключения состояние теряется.

## Файлы

В каждой платформенной папке:

```text
протокол.md
README.md
ПОЯСНЕНИЯ.md
CMakeLists.txt
SERVER/
    server.cpp
CLIENT/
    client.cpp
```

Каждый исходник собирается отдельно. Классов-обёрток и общих заголовков нет. `receiveLine` собирает TCP-строку до LF, `sendLine` досылает все байты, `handleCommand` выполняет вариант 5, `printResponse` разбирает ответ на клиенте.

Сервер обслуживает клиентов по очереди. Таймаутов ожидания нет. /quit завершает одну сессию, Ctrl+C останавливает сервер. Побайтовое чтение выбрано для простоты объяснения коротких учебных сообщений.

Для сдачи выбрать одну платформу и упаковать содержимое её папки: протокол должен лежать в корне ZIP рядом с SERVER и CLIENT. Команды упаковки есть в README обеих платформ.
