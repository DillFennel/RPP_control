## Задание
Сервис генерации случайных данных

Функциональность:
- Генерация строки заданного типа и длины. Типы: цифры, буквы, буквы и цифры, знаки пунктуации.
- Установка seed генератора
- Проверка, могла ли строка быть сгенерирована для указанного типа (Эвристика: соответствие символов типу; гарантии нет)
- История последних 5 сгенерированных значений

Ошибки: неизвестный тип, неверная длина (<=0 или слишком большая), неверный seed, неверный формат

## API
/generate <type> <size>
Клиент передает серверу type: [DIGITS, LETTERS, ALNUM, PUNCT] и размер генерируемой строки size, причем 0 < size <= 128.
Сервер возвращает рандомно сгенерированную строку, заданного типа и размера.
/seed <seed>
Клиент передает серверу seed, причем 0 <= seed <= 4294967295.
Сервер возвращает клиенту статус OK SEED <число> или ERR <КОД> <описание> если при произошла ошибка
/check <type> <string>
Клиент передает серверу string, причем 0 < string.size <= 128, и тип 
Сервер возвращает клиенту статус OK CHECK YES, OK CHECK NO или ERR <КОД> <описание> если при проверки произошла ошибка
/history
Клиент вызывает у сервера команду /history без параметров
Сервер возвращает до 5 последних сгенерированных им строк

## Описание протокола
Использован протокол TCP поверх IPv4. TCP, в отличие от UDP, позволяет устанавливать надежное соединение между
сервером и клиентом, контролировать, что все пакеты дошли. Даже если пакеты дошли в перепутанном порядке, TCP востановит порядок и приложение получит пакеты в правильном порядке.
Сервер и клиент написаны на C++.
Сервер принимает подключения на порту 12345 на всех локальных IPv4-адресах. Клиент по умолчанию подключается к 127.0.0.1:12345.
Сервер разворачивается по умолчанию на ANY_ADDR, то есть на всех локальных адресах, клиент будет подключаться к серверу через 127.0.0.1:12345, где 127.0.0.1 это IPv4 адрес, а 12345 это порт.

Сервер и клиент начинают с того, что создают TCP-сокеты при помощи socket(AF_INET, SOCK_STREAM, 0). Тут
AF_INET показывает, что мы используем IPv4, SOCK_STREAM показывает, что мы используем TCP, а 0 обозначает выбор протокола по умолчанию для этой комбинации, в данном случае это TCP.

Сервер потом настраивает свой сокет через setsockopt(serverSocket, SOL_SOCKET, SO_REUSEADDR, &reuse, sizeof(reuse)),
без этого порт какое-то время будет в таймауте после отсановки сервера. С такой настройком его можно сразу переиспользовать.

Затем сервер и клиент создают структуры sockaddr_in address{}. На сервере структура содержит локальный адрес и порт для bind. На клиенте там адрес и порт сервера для connect.

Затем сервер призязывает свой сокет к address через bind(serverSocket, (const sockaddr*)&address, sizeof(address)).
Клиенту это не нужно, так как он автоматически получит адрес при попытке connect к серверному сокету.

Сервер вызывает listen и ожидает подключения через accept. Клиент вызывает connect. После подключения accept возвращает серверу отдельный сокет для обмена данными с этим клиентом.

После того, как сервер и клиент установили соединение, сервер ждет от клиента команду, приветствие не отправляет.
Запрос и ответ это одна ASCII-строка, заканчивающаяся LF (`\n`), поддерживается обработка также CRLF (`\r\n`). Максимум 1024 байта содержимого без LF/CRLF. Допустимы печатные ASCII-символы и табуляция. Команды чувствительны к регистру, начинаются с `/` и пишутся строчными буквами. Типы пишутся прописными буквами. Аргументы разделяются пробелами/табуляцией, пробелы по краям допустимы.

На одну полную команду сервер должен отправить один ответ. Клиент ожидает ответ перед следующей командой.

## Типы и ограничения

| Тип | Допустимые символы |
| --- | --- |
| DIGITS | Цифры `0`–`9` |
| LETTERS | Латинские `A`–`Z` и `a`–`z` |
| ALNUM | Латинские `A`–`Z`, `a`–`z` и цифры `0`–`9` |
| PUNCT | 32 ASCII-символа с кодами 33–47, 58–64, 91–96, 123–126 |

В ALNUM каждый символ выбирается из общего алфавита: одновременное наличие букв и цифр не обязательно. Пробел не входит ни в один тип. Русские буквы не поддерживаются.
Длина генерируемой или проверяемой строки: 1–128 символов включительно. В ASCII один символ занимает один байт. Этот предел выбран для протокола, так как все пять значений истории помещаются в один ответ до 1024 байт.

Числа записываются десятичными цифрами, без знака, дробной части и экспоненты. Ведущие нули допустимы. Seed может принимать значения 0–4294967295 включительно.

## Состояние

В каждом соединении отдельные `std::mt19937` и история. Начальный seed — **5489**, история пуста. После отключения состояние уничтожается. Сервер обслуживает соединения последовательно.
/seed заново инициализирует генератор. Один seed и одна последовательность /generate воспроизводят результаты в той же реализации программы. Побайтовое совпадение между разными стандартными библиотеками C++ не является требованием протокола.
/seed не очищает историю. Только успешная /generate добавляет результат в конец истории и удаляет самый старый, если значений стало больше пяти. /check и /history не изменяют генератор. Ошибочная команда не меняет ни генератор, ни историю.

## Команды

Угловые скобки обозначают параметры и не передаются. Квадратные скобки обозначают необязательную часть и тоже не передаются.

| Запрос | Действие | Успешный ответ |
| --- | --- | --- |
| `/generate <тип> <длина>` | Сгенерировать строку, добавить в историю | `OK STRING <строка>` |
| `/seed <число>` | Установить seed | `OK SEED <число>` |
| `/check <тип> <строка>` | Проверить принадлежность всех символов алфавиту типа | `OK CHECK YES` или `OK CHECK NO` |
| `/history` | Получить до пяти последних результатов | `OK HISTORY <количество> [<строка1> ... <строкаN>]` |
| `/quit` | Завершить текущую сессию | `OK BYE`, затем закрытие соединения |

История выдаётся от старого значения к новому. Пустая история: `OK HISTORY 0`. Значения непустые и без пробельных символов, поэтому разделение пробелом однозначно, в том числе для PUNCT.

/check возвращает YES, только если каждый символ входит в алфавит типа. NO — обычный результат проверки. YES не доказывает, что строку сгенерировал именно этот сервер, и не проверяет соответствие seed. Отсутствие строкового аргумента — ошибка формата.

## Ошибки

Формат: `ERR <КОД> <описание>`. Описание непустое и предназначено для человека; точный текст может меняться.

| Код | Причина | Действие |
| --- | --- | --- |
| UNKNOWN_COMMAND | Неизвестная команда | Продолжить сессию |
| BAD_FORMAT | Пустая команда, неверное число аргументов, запрещённые байты | Продолжить сессию |
| BAD_TYPE | Неизвестный тип | Продолжить сессию |
| BAD_LENGTH | Формат длины неверен, длина вне 1–128, слишком длинный аргумент /check | Продолжить сессию |
| BAD_SEED | Формат seed неверен или число вне 0–4294967295 | Продолжить сессию |
| LINE_TOO_LONG | Сообщение длиннее 1024 байт | Попытаться отправить ошибку, закрыть сессию |
| INCOMPLETE_MESSAGE | Отправка завершилась посреди сообщения, до LF | Попытаться отправить ошибку, закрыть сессию |

Порядок проверок: граница/размер сообщения, допустимые байты, название команды, число аргументов, тип, длина или seed. Для /check длина проверяется перед принадлежностью символов алфавиту.

EOF без незавершённой строки завершает сессию. При сетевом обрыве отправить ответ может быть невозможно. После /quit следующие команды этого соединения не исполняются.

## Примеры

Метки C/S не передаются. Каждая строка заканчивается LF. Случайные значения иллюстративные: конкретный результат /generate зависит от состояния генератора и стандартной библиотеки.

### 1. Генерация и история

```text
C: /history
S: OK HISTORY 0
C: /seed 42
S: OK SEED 42
C: /generate DIGITS 4
S: OK STRING 7310
C: /generate LETTERS 3
S: OK STRING aZb
C: /history
S: OK HISTORY 2 7310 aZb
C: /quit
S: OK BYE
```

### 2. Проверка строк

```text
C: /check DIGITS 12345
S: OK CHECK YES
C: /check DIGITS 12a45
S: OK CHECK NO
C: /check ALNUM ABC
S: OK CHECK YES
C: /check PUNCT !?.,
S: OK CHECK YES
C: /quit
S: OK BYE
```

### 3. Ошибки

```text
C: /generate UNKNOWN 10
S: ERR BAD_TYPE Use_DIGITS_LETTERS_ALNUM_PUNCT
C: /generate DIGITS 0
S: ERR BAD_LENGTH Expected_1_to_128
C: /generate DIGITS 129
S: ERR BAD_LENGTH Expected_1_to_128
C: /seed -1
S: ERR BAD_SEED Expected_0_to_4294967295
C: /generate DIGITS
S: ERR BAD_FORMAT Expected_type_and_argument
C: /history
S: OK HISTORY 0
C: /quit
S: OK BYE
```
