# Вариант 5. Генератор случайных последовательностей

## Соединение и сообщения

- TCP, IPv4, порт сервера 12345. Клиент — консольная программа на C++.
- После подключения сервер ждёт команду, приветствие не отправляет.
- Запрос и ответ — одна ASCII-строка, заканчивающаяся LF (`\n`). Допускается CRLF (`\r\n`). Максимум 1024 байта содержимого без LF/CRLF.
- Допустимы печатные ASCII-символы и табуляция. Команды чувствительны к регистру, начинаются с `/` и пишутся строчными буквами. Типы пишутся прописными буквами.
- Аргументы разделяются пробелами/табуляцией; пробелы по краям допустимы.
- На одну полную команду — один ответ. Клиент ожидает ответ перед следующей командой.
- Строковые аргументы не содержат пробельных символов. Кавычки и обратная косая черта — обычные символы: экранирования и обрамления кавычками нет.

## Типы и ограничения

| Тип | Допустимые символы |
| --- | --- |
| DIGITS | Цифры `0`–`9` |
| LETTERS | Латинские `A`–`Z` и `a`–`z` |
| ALNUM | Латинские `A`–`Z`, `a`–`z` и цифры `0`–`9` |
| PUNCT | 32 ASCII-символа с кодами 33–47, 58–64, 91–96, 123–126 |

В ALNUM каждый символ выбирается из общего алфавита: одновременное наличие букв и цифр не обязательно. Пробел не входит ни в один тип. Русские буквы не поддерживаются.

Длина генерируемой или проверяемой строки: **1–128 символов** включительно. В ASCII один символ занимает один байт. Этот предел выбран для протокола: все пять значений истории помещаются в один ответ до 1024 байт.

Числа записываются десятичными цифрами, без знака, дробной части и экспоненты. Ведущие нули допустимы. Seed: **0–4294967295** включительно.

## Состояние

В каждом соединении отдельные `std::mt19937` и история. Начальный seed — **5489**, история пуста. После отключения состояние уничтожается. Сервер обслуживает соединения последовательно.

/seed заново инициализирует генератор. Один seed и одна последовательность /generate воспроизводят результаты в той же реализации программы. Побайтовое совпадение между разными стандартными библиотеками C++ не является требованием протокола.

/seed не очищает историю. Только успешная /generate добавляет результат в конец истории и удаляет самый старый, если значений стало больше пяти. /check и /history не изменяют генератор. Ошибочная команда не меняет ни генератор, ни историю.

## Команды

Угловые скобки обозначают параметры и не передаются. Квадратные скобки обозначают необязательную часть и тоже не передаются.

| Запрос | Действие | Успешный ответ |
| --- | --- | --- |
| `/generate <тип> <длина>` | Сгенерировать строку, добавить в историю | `OK STRING <строка>` |
| `/seed <число>` | Установить seed | `OK SEED <число>` |
| `/check <тип> <строка>` | Проверить принадлежность всех символов алфавиту типа | `OK CHECK YES` или `OK CHECK NO` |
| `/history` | Получить до пяти последних результатов | `OK HISTORY <количество> [<строка1> ... <строкаN>]` |
| `/quit` | Завершить текущую сессию | `OK BYE`, затем закрытие соединения |

История выдаётся от старого значения к новому. Пустая история: `OK HISTORY 0`. Значения непустые и без пробельных символов, поэтому разделение пробелом однозначно, в том числе для PUNCT.

/check возвращает YES, только если каждый символ входит в алфавит типа. NO — обычный результат проверки. YES не доказывает, что строку сгенерировал именно этот сервер, и не проверяет соответствие seed. Отсутствие строкового аргумента — ошибка формата.

## Ошибки

Формат: `ERR <КОД> <описание>`. Описание непустое и предназначено для человека; точный текст может меняться.

| Код | Причина | Действие |
| --- | --- | --- |
| UNKNOWN_COMMAND | Неизвестная команда | Продолжить сессию |
| BAD_FORMAT | Пустая команда, неверное число аргументов, запрещённые байты | Продолжить сессию |
| BAD_TYPE | Неизвестный тип | Продолжить сессию |
| BAD_LENGTH | Формат длины неверен, длина вне 1–128, слишком длинный аргумент /check | Продолжить сессию |
| BAD_SEED | Формат seed неверен или число вне 0–4294967295 | Продолжить сессию |
| LINE_TOO_LONG | Сообщение длиннее 1024 байт | Попытаться отправить ошибку, закрыть сессию |
| INCOMPLETE_MESSAGE | Отправка завершилась посреди сообщения, до LF | Попытаться отправить ошибку, закрыть сессию |

Порядок проверок: граница/размер сообщения, допустимые байты, название команды, число аргументов, тип, длина или seed. Для /check длина проверяется перед принадлежностью символов алфавиту.

EOF без незавершённой строки завершает сессию. При сетевом обрыве отправить ответ может быть невозможно. После /quit следующие команды этого соединения не исполняются.

## Примеры

Метки C/S не передаются. Каждая строка заканчивается LF. Случайные значения иллюстративные: конкретный результат /generate зависит от состояния генератора и стандартной библиотеки.

### 1. Генерация и история

```text
C: /history
S: OK HISTORY 0
C: /seed 42
S: OK SEED 42
C: /generate DIGITS 4
S: OK STRING 7310
C: /generate LETTERS 3
S: OK STRING aZb
C: /history
S: OK HISTORY 2 7310 aZb
C: /quit
S: OK BYE
```

### 2. Проверка строк

```text
C: /check DIGITS 12345
S: OK CHECK YES
C: /check DIGITS 12a45
S: OK CHECK NO
C: /check ALNUM ABC
S: OK CHECK YES
C: /check PUNCT !?.,
S: OK CHECK YES
C: /quit
S: OK BYE
```

### 3. Ошибки

```text
C: /generate UNKNOWN 10
S: ERR BAD_TYPE Use_DIGITS_LETTERS_ALNUM_PUNCT
C: /generate DIGITS 0
S: ERR BAD_LENGTH Expected_1_to_128
C: /generate DIGITS 129
S: ERR BAD_LENGTH Expected_1_to_128
C: /seed -1
S: ERR BAD_SEED Expected_0_to_4294967295
C: /generate DIGITS
S: ERR BAD_FORMAT Expected_type_and_argument
C: /history
S: OK HISTORY 0
C: /quit
S: OK BYE
```
