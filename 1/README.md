# Самостоятельная работа №1: простые примеры на сокетах

Основа — порядок действий из презентации «Библиотека SOCKETS (Введение)»: `socket → bind → listen → accept` на сервере и `socket → connect` на клиенте.

В каждой версии всего **два исходника**: `server/server.cpp` и `client/client.cpp`. Классов-обёрток, отдельных заголовков и общего сетевого модуля нет. Каждый файл собирается самостоятельно. Чтение TCP-строки и её отправка вынесены в две небольшие функции.

- [macOS: сборка и запуск](macos/README.md).

## Что добавлено к примеру из презентации

В слайдах показывается один обмен сообщениями. Для требований самостоятельной нужны цикл команд, состояние клиента и обработка ошибок. Поэтому добавлены:

- `receiveLine`: чтение до LF по одному байту;
- `sendLine`: отправка всей строки с LF с учётом частичного send;
- `handleCommand`: команды GET, SET, ADD, RESET, QUIT;
- проверка аргументов, переполнения и длины строки;
- разбор ответа клиентом.

Побайтовое чтение выбрано для понятности: при коротких учебных командах оно позволяет обойтись без дополнительного буфера незавершённых сообщений. Для больших объёмов данных эффективнее читать блоками.

## Структура каждой платформенной папки

```text
протокол.md
README.md
CMakeLists.txt
server/
    server.cpp
client/
    client.cpp
```

Для сдачи выбрать одну платформу и упаковать содержимое её папки. Протокол должен оказаться в корне архива. Копии протокола в корне `1`, `windows` и `macos` совпадают; при изменении общей логики обновить их вместе.

Сервер обслуживает одного клиента за раз. Состояние — одна переменная `long long value` внутри цикла приёма соединений. При каждом подключении она равна 0. Индивидуальный вариант ещё не известен: учебный счётчик нужно заменить под задание.

Сервер останавливается обычным Ctrl+C, ОС освобождает ресурсы процесса. Сессию клиента штатно завершает QUIT; клиент и сервер явно закрывают её сокеты. Таймаутов ожидания в этой простой версии нет.

Упрощённая версия macOS собрана без предупреждений и прошла 47 сетевых и консольных проверок через 127.0.0.1. Windows-версия в текущей среде не собиралась и не запускалась. Подробности — в README для платформ. Старая расширенная заготовка доступна в истории Git до этого упрощения.
